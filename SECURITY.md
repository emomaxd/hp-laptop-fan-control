# Security policy

Fan control failures can damage hardware or cause thermal shutdowns. Do not
publish an exploit or a reproducible unsafe PWM sequence in a public issue.

Report security and thermal-safety problems through
[GitHub private vulnerability reporting](https://github.com/emomaxd/hpfand/security/advisories/new).

Include the affected version, board ID, kernel version and the shortest safe
reproduction available. Do not include serial numbers or machine UUIDs.

Only the latest release receives security fixes.
